# INNA — Masaż · Joga

## Preview
Open `index.html` in a modern browser. The project uses relative assets in `assets/`.

## Edit
- `index.html` — page structure and static content
- `styles.css` — design system and responsive layout
- `script.js` — Polish/Russian content, massage catalogue, filters, modal details, hero slider, certificate viewer and booking request
- `assets/` — supplied and prepared image assets

## Booking
The website contains its own booking request form. It collects the service, selected duration, matching displayed price, preferred date/time and contact details, then opens WhatsApp with the prepared message. It does not claim to read live availability or confirm an appointment automatically. Booksy is used only as the source for external reviews.

Before launch, confirm all pending prices/durations, the displayed address and contact number, and connect the form to a backend or scheduling service if server-side submissions and availability are required.
